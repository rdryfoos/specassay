# Night walking

The one feature this sample carries, so the registry's IDs are claimed by a
spec and the exact-set rule holds.

- US-WALK-01 — the story. A walker is told the next turn out loud.
- FR-WALK-01 — the requirement under it. Turns are spoken, never shown.
- AC-WALK-01 — the criterion under that. The turn is spoken once, fifty
  metres ahead.
- US-PHONE-01 — a second story, with nothing built under it yet.
